# Apples, oranges, pineapple

**Truth:** Three quotes for the 'same' bathroom come back at $14k, $31k and $52k because each priced a different job.

**Twist:** Literal visual metaphor: homeowner holds up an apple, an orange and a pineapple ('this one included tiling').

## Beats
1. Hook: three quotes on the kitchen table: $14k / $31k / $52k
2. 'Which one's cheapest?' Holds up apple, orange, pineapple
3. 'This one included tiling.' (pineapple)
4. Solution: every bidder prices the same lines, and QSME compares the totals on the same GST basis (never 'line by line'; see the week-3 calendar version)
5. CTA: 'Compare quotes properly — sign up at qsme.co.nz'

## Hook layers
Text: '$14k. $31k. $52k. Same bathroom?' / Visual: fruit / Verbal: 'Which one's cheapest?'
