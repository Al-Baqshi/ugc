# Same document. Five names.

**Situation:** A mixed-use tender in the Gulf. The client's QS calls it جدول الكميات, the German façade consultant sends a Leistungsverzeichnis, the Turkish subcontractor prices it poz poz from a Metraj cetveli, the steel supplier quotes against a 工程量清单, and the PM just says 'the BoQ'. Everyone is still arguing about whether prelims are included.

**Truth:** Construction is the same everywhere. Only the vocabulary changes, and the argument about preliminaries survives every translation.

**Twist:** Every word on screen changes language except one handwritten English sticky note that never moves: 'Prelims included??'

## Beats
1. 0–3s HOOK.
2. 3–9s One word swaps in place, each captured from the live site: schedule of quantities → جدول الكميات → Leistungsverzeichnis → Metraj cetveli → 工程量清单. VO: 'Five languages. One document.'
3. 9–12s A handwritten yellow sticky stays fixed over every version: 'Prelims included??' Caption: 'Some things don't need translating.' VO: 'And the same argument about prelims.'
4. 12–15s The Arabic page mirrors right-to-left. Caption: 'Right to left, properly.'
5. 15–19s The going-global poster: 'Now speaking 15 languages' · 'Yours next — tell us'. Caption (honest): 'The website speaks 15. The app speaks English, Spanish and Arabic, so far.'
6. 19–22s End card: 'Request a language or book a demo', qsme.build.

## Hook layers
- **Text:** Same document. Five names.
- **Verbal:** Same document. Five names. Same argument about prelims.
- **Visual:** The live qsme.build language switcher cycles English → العربية (the whole layout mirrors right-to-left) → Deutsch → Türkçe → 简体中文, and the schedule-of-quantities word changes each time.
- **Audio:** A soft click per language switch

## Footage plan
- capture-public: qsme.build language switcher and the localised pages/blog where the schedule-of-quantities word appears in Arabic, German, Turkish and Chinese. Skip Spanish, whose body text is still English
- kinetic: The fixed sticky note, word-swap captions, the honest app-languages line, and assets/qsme/brand/qsme-build-going-global.png animated as the end card

**CTA:** Request a language or book a demo, qsme.build

**Why now:** The 15-language site launched 27 September and this is the honest launch-moment piece. It's the cheapest idea in the set (public capture + kinetic only) and can ship in week 1.

## Risks
- The 15 languages are the website; the app is English, Spanish and Arabic. The on-screen line must say so.
- Spanish product pages still show English body text, and there's been no native review, so don't zoom into long translated paragraphs.
- The humour is the shared prelims argument, never accents or nationalities.
- Check that each word (Metraj cetveli, poz poz) is actually on the live page before capture.
- Ownability is weak, since any translated site could do this. This is the lowest-scoring idea; keep it as a cheap brand beat, not a lead.
