# Is QSME ISO 27001 certified? No.

**Situation:** A main contractor's procurement lead is on row one of a vendor security questionnaire ('ISO 27001 certified? Y/N'), and every software vendor so far has answered with a badge wall and a 'roadmap'.

**Truth:** Procurement can smell a badge that wasn't earned, and vague security answers stall software purchases for weeks.

**Twist:** The vendor's own website answers in one word, 'No.', then lists exactly what is in place and what isn't. Deadpan honesty is the pattern interrupt.

## Risks
- Needs owner sign-off: leading with 'No' is deliberate, but it may worry some enterprise buyers.
- Quote the page exactly and never paraphrase upward ('certified soon', 'by 2027', 'basically compliant'). No badges, and no SSO, MFA, GDPR, pen-test or data-residency claims.
- Backups are only 'merged': repeat the page's own sentence and say nothing about nightly runs or past incidents.
- The hosting region is 'confirmed with sales', so don't name one.
