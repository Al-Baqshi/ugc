# The main contractor went bust (use case: construction)

**Truth (owner):** on a construction job the subcontractor finishes the stage and doesn't get paid because the main contractor went bankrupt; with the stage money held in escrow before work starts, that wouldn't happen.
**Twist:** the same job, replayed with BitRegalo: the stage money is held in a contract before the first hammer swing; the request for proposal, every bid and the award are on record; the project acts as an entity.
**Also say:** this is one use case of many.
**Honesty gate:** claims checked against the escrow contracts and bitregalo.com before voicing (who can release, deadline return, insolvency). Test network + not audited + example names on screen.
