# Formats and hooks

## UGC formats
| Format | Shape | Good for |
|---|---|---|
| Talking head / confession | One person, selfie cam, direct to camera | Trust, pain points, founder story |
| POV skit | "POV: you just…" acted scene | Relatable humor |
| Two-character skit | Same person plays both roles, or person vs personified problem | Contrast, escalation |
| Before / after | Problem state → product → new state | Clear transformation |
| Green-screen reaction | Person over a screenshot/review/news | Commentary, social proof |
| "Things I wish I knew" / listicle | 3–5 quick points | Education, saves |
| Unboxing / first try | Real reaction to product | Product-led launches |
| Day-in-the-life | Montage with voiceover | Lifestyle fit |
| Street-interview style | Question to "strangers" | Engagement, opinions |
| Text-on-screen meme | Minimal footage + caption joke | Cheap, fast tests |

## Hook mechanics (use a different one per hook)
- **Call-out**: "If you [specific behavior], this is for you."
- **Pattern break**: something visually wrong or unexpected in frame 1.
- **Mid-action start**: open in the middle of the chaos.
- **Contrarian**: "Stop doing X." / "Unpopular opinion:"
- **Confession**: "I'm embarrassed to admit…"
- **Question with stakes**: "Why does nobody talk about…?"
- **Visual promise**: show the end result first, then rewind.
- **Dialogue cold-open**: a line of conversation with no context.

Each mechanism is the idea behind a hook. Build it out in layers (text/verbal/visual/audio). See direct-response.md → Hook layering.

## Defaults
- Vertical 9:16, captions always on. Organic 15–30s, paid 30–40s.
- First frame = hook. No logos or intros up front.
- ~2.5 spoken words/sec → 30s ≈ 70 words.
